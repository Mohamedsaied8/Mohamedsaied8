I build firmware and system software in **C and modern C++** — from bare-metal ARM Cortex-M to **embedded Linux and QNX** — and I've been doing it for more than ten years.

- 🚗 **3 years at Luxoft on the BMW team**, building Adaptive AUTOSAR applications on the Vector stack (SOME/IP, IPC, Franca, Bazel)
- 🤖 Now writing **ROS 2 / modern C++** software for autonomous mobile robots at **Robotics Corner**
- 🔐 Published research on **transformer-based intrusion detection for automotive CAN** (FTC 2026)
- 🛠️ Building **[RoboAgent](https://github.com/Mohamedsaied8/RoboAgent)**, an AI-native IDE for ROS 2, STM32 and ESP32 development
- 🧑‍🏫 I also design and teach embedded, QNX and robotics courses — many repos here are the labs I wrote for them
- 💼 **Open to senior embedded, robotics and automotive software roles** — remote or in Cairo
